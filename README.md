DENUE Map v1.0 (Beta)
Project Description
This application is an interactive map tool designed to visualize and manage economic units across Mexico using public data from the INEGI (National Institute of Statistics and Geography). It integrates the DENUE (National Statistical Directory of Economic Units) with the Marco Geoestadístico to provide precise location-based insights.
The map allows users to filter by municipality, track operational status, and manage data in real-time, tailored for logistics and operational management professionals.
Key Features

    Real-Time Status Updates: The information box updates instantly when a new status is selected.
    Custom Visuals: 
        Markers change color based on Delegation and Código Postal.
        A blue shadow highlights markers that have recently changed status.
    Advanced Filtering: 
        Filter data by Municipio using a left-side panel for better layout customization.
        Clear separation between CPS and Municipio data fields.
    Data Management:
        Downloadable JSON files include columns for 'status anterior', 'status nuevo', 'contactado', and 'sin respuesta'.
        Editable state fields within the database interface.
    Communication: Integrated functionality for WhatsApp messaging directly from the map interface.

Data Sources

    DENUE Provides identification, location, economic activity, and size data for over 5 million establishments nationwide.
    Marco Geoestadístico: Uses official INEGI shapefiles for State (AGEE), Municipal (AGEM), and Basic (AGEB) boundaries to ensure geographic accuracy.
    Catálogo Único: Utilizes official keys and names for all Mexican municipalities and localities.

How to Use

    Load the Map: The application loads the base map using OpenStreetMap and overlays INEGI geostatistical layers.
    Filter: Use the left-side panel to select a specific Municipio or Estado.
    Interact: Click on a marker to view details. Update the status via the bottom-left control panel.
